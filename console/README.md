# Локальная страница консоли Math Coding

Та же консоль, что работает как плагин Paseo, но запускается локально в браузере и не требует Пасео.

## Что это

Один интерфейс, два хоста. Компоненты, контракты данных и серверное ядро общие; различаются только оболочки:

- **Плагин Paseo** — `plugin/math-coding-console`, панель рабочей области и экран настроек.
- **Локальная страница** — этот каталог, обычная страница в браузере.

Общий слой лежит в пакете плагина, потому что публикуемый пакет обязан содержать все импортируемые модули. Страница импортирует его внутрь и никогда не импортирует наружу.

Первый экран — очередь человека: что ожидается, как это проверяется, каково записанное свидетельство, какое решение остаётся за человеком и какой файл предмета открыть, чтобы проверить. Состояние в очереди берётся из канонической карты, а не из журнала наблюдений.

Карточка **Manual steps you can take now** перечисляет ручные шаги метода, которые человек может совершить сейчас, и позволяет совершить их: `review-source`, `record`, `waive`, `authorize`. Шаги исполняет сам `mathc`, а не страница: аргументы строит общий билдер в пакете плагина, поэтому показанная человеку команда и выполненная команда совпадают. Перед запуском сервер перечитывает карту и отказывает, если шага в ней нет. После действия карта перечитывается заново.

## Запуск

```sh
cd console
npm install
npm run build
npm run serve -- --root /path/to/project
```

Сервер печатает локальный адрес, например `http://127.0.0.1:5173/`. Открывать нужно именно его.

Для разработки интерфейса: `npm run dev` (Vite с горячей перезагрузкой).

## Как это устроено

- `shared/schemas.ts` — чистые контракты: схемы входа и выхода для снимка, карточки утверждения, журнала наблюдений, запуска проверок и чтения файла, а также схема настроек. Плагин оборачивает их в вызовы Пасео, страница отдаёт их по локальному HTTP.
- `server/core/operations.ts` — общее ядро: шесть операций над проектом (снимок, карточка, журнал, запуск, чтение файла, решение человека) и очередь, которая сериализует операции одной рабочей области.
- `client/host/contract.ts` — полный список хостовых примитивов, которые может использовать общий интерфейс: иконки, модальное окно, поля ввода, элементы настроек, вызовы, настройки, буфер обмена и уведомления.
- `client/host/context.tsx` — контекст хоста. Пасео и браузер подставляют в него свою реализацию.
- `console/src/server.ts` — локальный сервер: только адрес обратной петли, один фиксированный корень проекта, те же схемы проверки данных.
- `console/src/browser-host.tsx` — браузерная реализация хостовых примитивов.

## Граница доверия

Страница показывает ровно то, что отдаёт каноническая карта `mathc map --json`. Свежесть, независимость и достижимость контроля не пересчитываются на стороне страницы. Если карта недоступна, страница показывает ошибку, а не прежний успешный результат.

Запуск проверок выключен по умолчанию и требует разрешения в настройках и подтверждения в интерфейсе. Настройки хранятся вне проекта, в `~/.config/math-coding-console/settings.json`, поэтому чтение страницы никогда не меняет живое дерево.

Ручные решения выключены по умолчанию отдельной настройкой **Allow human decisions**: пока она закрыта, страница показывает шаги, но не может их совершить. Само решение требует явного подтверждения и выполняется программой. Имя автора — запись в журнал, а не аутентификация.

Пути проекта не приходят из браузера: корень задаётся при запуске сервера. Сервер принимает только локальные соединения и отклоняет запросы с чужим заголовком `Origin`.

Чтение файла предмета тоже ограничено корнем проекта: путь относительный, без выхода за пределы дерева (в том числе через symlink), с ограничением по размеру. Открывается только обычный файл: именованный канал внутри дерева отклоняется сразу, а не ждёт писателя. Сервер читает файл и ничего в нём не меняет.

## Язык интерфейса

Страница двуязычная: английский и русский, тем же каталогом и тем же резолвером, что и плагин.

- По умолчанию страница следует языку браузера (`navigator.language`) и переключается на русский, если браузер на нём.
- Настройка `locale` в экране настроек переопределяет это: `auto` (следовать браузеру), `en`, `ru`.
- Каталоги и правила перевода — в пакете плагина (`shared/locales/`, `client/i18n/`); страница их не дублирует.
