# Измерение независимого onboarding v5

## Условие

Новый агент получил только:

- установленный бинарь `mathc 5`;
- user-scope skill `math-coding`;
- пустой Git-проект `/home/az/Projects/math-coding-v5-onboarding`.

Исходники, README и AGENTS репозитория метода ему не предоставлялись. Задача:
подключить math-coding, создать одно проверяемое требование с настоящим
отрицательным control, довести его до подтверждённого состояния, установить
agent page и пройти doctor.

## Результат

Первый независимый проход завершился успешно:

- `adopt`, `init`, `goal`, `add`, `run`, `map`, `next`, `context`,
  `install` и `doctor` были выполнены без чтения реализации;
- claim `R1` получил `holds`, общий verdict — `green`;
- control изменил предмет, verifier после control упал;
- живой subject не изменился;
- `doctor` прошёл;
- коммитов и публикации не было.

Агент подтвердил также границы: неэффективный control дал `inconclusive`,
ручное изменение предмета — `outdated`, verifier без control — `refuted`,
существующий `spec.json` — отказ с кодом 2.

## Найденные пробелы и исправления

1. Не было `mathc-stand --help` и объяснения стоимостных параметров.
   Добавлена полная справка с колонками, единицами и примером.
2. Общий help не описывал отдельные глаголы. Добавлен
   `mathc help COMMAND`, включая допустимые значения и коды выхода.
3. `uncovered` не ограничивался scope цели и показывал сгенерированный
   `AGENTS.md`. Покрытие теперь ограничено aim, служебные файлы метода
   исключены, а skill показывает, как включить verifier-файл в scope.
4. Skill не содержал готового примера для проекта без кода. Добавлены
   маленький subject, честная проверка, control и полный command flow.
5. `run` не сообщал явно, что отрицательный control доказан. Добавлена
   отдельная строка `negative control proven`.

После первых исправлений второй независимый агент обнаружил, что snapshot
изолированной копии терял executable-бит. Это позволяло control упасть из-за
не связанной с предметом ошибки запуска. Копирование теперь сохраняет режим
файла, digest предмета включает права, а готовый skill recipe не зависит от
exec-бита.

После исправлений полный build/test run, default/portable smoke и внешний
onboarding проходят повторно.
