# Замер 2026-11-01 — метод на трёх чужих проектах

> Это запись измерения, а не отчёт о нём. Процедура и числа — чтобы
> результат можно было повторить или оспорить.

## Предметы

Три проекта, не этот. Каждый — чистая копия, потому что метод пишет
в проект один файл (`spec.json`) и оставляет след (`.math/trail.jsonl`),
а чужой репозиторий трогать нельзя.

| Проект | Что это | Стек | Файлов |
|---|---|---|---|
| `glass` | витрина стекла и занятий | TypeScript, Next.js | 43 |
| `geopulse` | сервис мониторинга | Python | 743 |
| `wavecode` | веб-плеер | TypeScript, React | 784 |

`wavecode` — особенный: он несёт **корпус прежней версии** — 128 решений
и 212 аттестаций, 20 650 строк YAML, 14% текста проекта. Для четвёртой
версии этот корпус **невидим**: ни одного утверждения он не порождает, и
карта показывает все 784 файла как не покрытые. Это и есть измерение
переносимости: единица изменилась, и перенос записей о том, что менялось,
в утверждения о том, что верно — подмена.

## Объявленные утверждения

В [`2026-11-01/`](.) лежат спецификации, объявленные на каждом проекте:
цель, область и утверждения с требованиями. По одному утверждению на
проект — «проверки проходят» и одно суждение, которое машина решить не
может.

## Процедура

```sh
# 1. копия предмета
git clone <исходный-репозиторий> /tmp/adopter-<имя>

# 2. спецификация: цель и утверждения
cp docs/measurements/2026-11-01/<имя>.spec.json /tmp/adopter-<имя>/spec.json

# 3. проверки и карта
mathc.exe --root /tmp/adopter-<имя> run
mathc.exe --root /tmp/adopter-<имя> map

# 4. измерение со сравнением
./_build/default/bin/stand.exe /tmp/adopter-<имя> ...
```

## Числа

```text
project                            claims uncovered  caught  needs work  protocol  price-arm  overhead
glass                                     2         7       0           1      3.4        2.3      1.1
geopulse                                  2        70       0           1      1.6        1.4      0.2
wavecode                                  2       313       1           0      9.6        9.2      0.4
```

**Одна цифра в этой таблице была исправлена, и вот почему.** Стенд печатает
накладные как разность: `overhead = protocol - price-arm`
(`bin/stand.ml:296`). Поэтому напечатанная тройка обязана сходиться, а строка
glass была записана как 3.4 / 2.2 / 1.1 — такую стойка стенд напечатать не
мог: 3.4 − 2.2 = 1.2. Контроль 2.3 даёт 1.1, и с этой цифрой сходится всё:
разность в каждой строке, сумма колонки накладных 1.7 и разность итогов
14.6 − 12.9 = 1.7. Исправлено число, а не результат: 2.2 записано вместо
2.3, и это опечатка переноса, а не другое измерение.

Копии проектов, на которых считалось, жили во временном каталоге и не
сохранились, поэтому пересчитать заново нельзя — сверка с тем, что стенд
печатает по построению, это всё, что доступно. Запись остаётся первичной, и
README ссылается на неё и ни на что другое.

Замер **с поломкой**: один файл в `wavecode` сломан, и утверждение
«проверки проекта проходят» стало `refuted`, вердикт — красный, `run`
вышел с кодом 1.

## Что эти числа значит и что не значит

**Значат.** Цену протокола: накладные расходы — около 13% времени контрольной
руки, а на малых проектах — в пределах шума измерения. Размер непокрытой
поверхности: 390 отслеживаемых файлов, о которых ни одно утверждение не
говорит. И то, что метод ловит поломку там, где её видит.

**Не значат.** Ничего о полезности. Числитель меры — «пойманные дефекты»,
и здесь их 0 или 1; а полезность определяется тем, поймал ли метод
**сверх** агента без протокола. Этой руки нет — она и есть шаг **G**
плана. До неё у метода есть знаменатель и сырьё числителя, но не
отношение.

И ещё: **цена дефекта** — величина о проекте, а не о методе. Её
объявляет тот, кто знает, сколько стоит его дефект. Метод не угадывает
цены и потому не печатает отношение, пока цены не объявлены.
