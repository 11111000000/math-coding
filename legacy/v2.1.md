# Math-coding 2.1 baseline

The complete math-coding 2.1 source is preserved at the remote Git tag
`v2.1-final`, pointing to commit `0756282`.

Version 2.1 remains historical evidence and a source of regression cases.
Its packet format, lifecycle, CLI semantics, and agent protocol are not
active in the 3.0-alpha branch.

Restore or inspect it with:

```sh
git switch --detach v2.1-final
```

Known v2 failures must be translated into 3.0 conformance fixtures before
the corresponding implementation is removed from this branch.
