Рабочий цикл

Основной цикл: init, goal, add, run и map; next называет одно конкретное следующее действие. Читающие глаголы не изменяют рабочее дерево; контроли исполняются в изолированных копиях; человеческие решения записываются явно с автором и положенными каждому решению данными. mathc help COMMAND описывает каждый глагол и работает до создания спецификации. Полная модель находится в канонической методологии.

Основной цикл

Пример цикла в проекте, где обязательство подтверждено:

$ mathc init $ mathc goal "платежи остаются идемпотентными" "src/,test/" "anna" $ mathc add retry-safety "повторное списание не применяется дважды" \ src/payments.ml,test/payments.ml \ "двойное списание проходит набор тестов" fact \ --requirement "verifier:dune runtest test/payments.exe" \ --control "sed -i 's/dedupe//g' src/payments.ml" $ mathc run $ mathc map verdict: green retry-safety holds $ mathc next next: nothing to do - declared evidence is current and the tree is covered
глаголчто делаеттрогает дерево?
init / goalсоздают спецификацию; записывают цель и владельца, заданных человекомпишет spec.json
addобъявляет обязательство: требование, scope, опровержитель, регистр, проверка, контрольпишет spec.json
runпроизводит свежие доказательства; контроли идут в изолированных копияхтолько след доказательств
map / next / contextвычисляют состояния, называют следующее действие, отдают капсулу агентуread-only

Привязка ADR

ADR хранит мотивацию и историю; math-coding ничего в него не пишет. import-adr печатает черновик, adopt перечисляет найденные источники, и только явный add --source привязывает обязательство к документу — по digest.

Решения человека

  • mathc record ID AUTHORITY --by WHO --outcome OUTCOME — записывает внешнее ревью для объявленного требования review:AUTHORITY. Существует ровно пять исходов: pass, fail, inconclusive, infrastructure-error, not-run.
  • mathc waive ID --by WHO --reason WHY --valid-for DAYS --recovery ACTION — ограниченное принятие риска. Это не pass, и оно не покрывает отказ.
  • mathc authorize --by WHO --reason WHY — работает только при наличии policy.json; это журнал разрешения, а не аутентификация.
  • mathc install обновляет маркированный блок в AGENTS.md; mathc doctor проверяет настройку и ничего не исправляет.

Коды выхода

кодзначение
0green, либо действие успешно
1red, либо отказ защищённого перехода
2ошибка вызова
3unknown или vacant — состояние невозможно вычислить

Повреждённый след доказательств не игнорируется и не считается отсутствием доказательств. Точные коды по глаголу показывает mathc help COMMAND.

Минимальное достаточное трение: обычная работа не требует карточек на каждый файл. Структура добавляется только там, где измерена польза.
