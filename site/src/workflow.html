Workflow

The main loop is init, goal, add, run and map; next names one concrete next action. Reading verbs never modify the working tree; controls run in isolated copies; human decisions are recorded explicitly with an author and decision-specific data. mathc help COMMAND describes each verb and works before any specification exists. The full model is in the canonical methodology (Russian).

The main loop

An example loop in a project whose claim is confirmed:

$ mathc init $ mathc goal "payments stay idempotent" "src/,test/" "anna" $ mathc add retry-safety "a retried charge is never applied twice" \ src/payments.ml,test/payments.ml \ "a duplicate charge passes the suite" fact \ --requirement "verifier:dune runtest test/payments.exe" \ --control "sed -i 's/dedupe//g' src/payments.ml" $ mathc run $ mathc map verdict: green retry-safety holds $ mathc next next: nothing to do - declared evidence is current and the tree is covered

Linking an ADR

ADRs keep motivation and history; math-coding never writes into them. import-adr prints a draft, adopt lists discovered sources, and only an explicit add --source binds a claim to the document — by digest.

Human decisions

  • mathc record ID AUTHORITY --by WHO --outcome OUTCOME — records an external review for a declared review:AUTHORITY requirement. Exactly five outcomes exist: pass, fail, inconclusive, infrastructure-error, not-run.
  • mathc waive ID --by WHO --reason WHY --valid-for DAYS --recovery ACTION — a bounded risk acceptance. It is not a pass and never covers a failure.
  • mathc authorize --by WHO --reason WHY — works only with a policy.json; it is a permission log, not authentication.
  • mathc approve --by WHO --reason WHY [--command CMD] — approves the commands the agent surface may execute in this project. Without an approval the surface refuses to declare or to run a command, and names it.
  • mathc install refreshes the marked block in AGENTS.md; mathc doctor checks the setup and fixes nothing.

The rest of the verbs

The loop above is the daily work. The remaining verbs serve the edges of a project, and none of them changes the working tree unless it says so.

verbwhat it does
contextprint the bounded task context as JSON — the capsule an agent receives
adoptdetect the ADR and the specification source directories, read-only
import-adr PATHread a MADR or adr-tools document and print a draft claim; neither the source nor spec.json is changed
import-junit PATHparse a JUnit XML report and print the exact counts of tests and failures
re-evaluatelist the claims whose source, definition or evidence requires a review
review-source ID --by OWNER --reason WHYbind a changed source after a human review; it records the previous digest, clears the waiver and still requires a fresh run
authorize --by WHO --reason WHYrecord an authorization for the current protected changes when policy.json exists; it is a journal, not authentication
approve --by WHO --reason WHY [--command CMD]approve the commands the agent surface may execute; the approval is bound to the commands themselves, and the surface refuses an unapproved command
doctorcheck git, the specification, the aim, the protected policy and the agent page without changing them
installupdate only the math-coding block in the AGENTS.md of the project; it installs no binaries
mcpserve the JSON-RPC tool surface over stdio

A claim with the register judgment is established only by an external human review: add requires review:WHO for it and refuses machine verifiers.

Reading the map without the terminal

The map can also be read in a browser. The console shows the same map, the queue of the human and the journal of observations, and it never computes a state of its own. The interfaces, piece by piece.

Exit codes

codemeaning
0green, or the action succeeded
1red, or a protected transition was refused
2invocation error
3unknown or vacant — the state is not established
4the run was stopped before it finished
5the tool could not answer — a broken specification or a broken repository

A corrupted evidence trail is neither ignored nor treated as absence of evidence. mathc help COMMAND prints the exact codes per verb.

Code 3 and code 5 are not the same answer. Code 3 says that the state is not established yet; code 5 says that the tool could not answer at all. A consumer that reads a broken tool as an unfinished project will wait for work that will never arrive.

Minimal sufficient friction: ordinary work needs no paperwork per file. Structure is added only where a measured benefit exists.
