Workflow

The main loop is init, goal, add, run and map; next names one concrete next action. Reading verbs never modify the working tree; controls run in isolated copies; human decisions are recorded explicitly with an author and decision-specific data. mathc help COMMAND describes each verb and works before any specification exists. The full model is in the canonical methodology (Russian).

The main loop

An example loop in a project whose claim is confirmed:

$ mathc init $ mathc goal "payments stay idempotent" "src/,test/" "anna" $ mathc add retry-safety "a retried charge is never applied twice" \ src/payments.ml,test/payments.ml \ "a duplicate charge passes the suite" fact \ --requirement "verifier:dune runtest test/payments.exe" \ --control "sed -i 's/dedupe//g' src/payments.ml" $ mathc run $ mathc map verdict: green retry-safety holds $ mathc next next: nothing to do - declared evidence is current and the tree is covered

Linking an ADR

ADRs keep motivation and history; math-coding never writes into them. import-adr prints a draft, adopt lists discovered sources, and only an explicit add --source binds a claim to the document — by digest.

Human decisions

  • mathc record ID AUTHORITY --by WHO --outcome OUTCOME — records an external review for a declared review:AUTHORITY requirement. Exactly five outcomes exist: pass, fail, inconclusive, infrastructure-error, not-run.
  • mathc waive ID --by WHO --reason WHY --valid-for DAYS --recovery ACTION — a bounded risk acceptance. It is not a pass and never covers a failure.
  • mathc authorize --by WHO --reason WHY — works only with a policy.json; it is a permission log, not authentication.
  • mathc install refreshes the marked block in AGENTS.md; mathc doctor checks the setup and fixes nothing.

Exit codes

codemeaning
0green, or the action succeeded
1red, or a protected transition was refused
2invocation error
3unknown or vacant — the state cannot be computed

A corrupted evidence trail is neither ignored nor treated as absence of evidence. mathc help COMMAND prints the exact codes per verb.

Minimal sufficient friction: ordinary work needs no paperwork per file. Structure is added only where a measured benefit exists.
