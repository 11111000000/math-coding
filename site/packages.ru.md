# Пакеты

math-coding 3.3.0. Каждая строка
> — это пара «решение–обязательство», известная ядру; каждый
> вердикт — текущая оценка ядра.

Сетка пакетов ниже — живой вывод команды:

```bash
mathc packages --format=html
```

Ядро выдаёт те же данные в виде JSON (`--format=json`) и в
виде таблицы фиксированной ширины (`--format=text`). HTML-форма
несёт атрибут `data-mathc-package-count`, позволяющий
инструментарию уровня сайта проверить число ядра без
повторного обхода решений.

## Зачем нужна поверхность пакетов

Позиция обеспечения качества проекта представляет собой граф пар
«решение–обязательство». Обход этого графа — работа ядра;
**публикация** его — работа поверхности пакетов. Без неё
каждому потребителю (сайту, агенту LLM, нижестоящему CI)
пришлось бы заново обходить `decisions/*.yaml` и воспроизводить
тот же разбор. С поверхностью же каждый потребитель читает
один и тот же вывод ядра.

## Как пользоваться

```bash
mathc packages --format=json | jq '.counts'
```

даёт живую сводку:

```text
{
  "fail": 0,
  "missing": 0,
  "no_store": 0,
  "pass": 23,
  "stale": 0,
  "total": 23,
  "unknown": 0,
  "waived": 0
}
```

Сетка ниже текста — HTML-форма, встроенная через `lib/render.ml`.
Ядро записывает обе формы.
